# 策略名称：Pullback EMA (均线回抽)
**核心逻辑**：在趋势行情中，不追高，耐心等待价格回调至均线密集区（价值回归）时介入。

**适用场景**：
- 趋势明确但已有一定涨幅，直接追高风险大
- 价格正在向 1h/4h 的 EMA20 或 EMA50 回靠

**交易规则**：
1. **入场**：
   - 在 EMA20 至 EMA50 的区域内分批挂单（Limit Buy/Sell）。
   - 等待价格测试均线支撑/阻力并出现 Pinbar (插针) 形态。
2. **止损**：
   - 放置在 EMA50 另一侧或前一个波段低点/高点之外。
3. **止盈**：
   - 前高/前低点（第一目标）。
   - 趋势延续的扩展位置（Fib 1.272/1.618）。
4. **指标过滤**：
   - 结合 Fibonacci 回撤位（0.382/0.5/0.618）共振效果最佳。

**订单类型**：
- 强制使用 `LIMIT` (限价) 订单。
- 是一种左侧偏右侧的交易方式（左侧挂单，或右侧企稳后Limit入场）。

# 开仓前确认清单（Pullback EMA 专用）

**总体原则**：只在“趋势明确、价格回到价值区、结构未被破坏”时做回抽介入；若价格仍在扩张或结构已被打穿，应优先 `wait`，而不是把追高/杀跌包装成回调交易。

## 1. 趋势确认（必须通过）

- ADX(4h) 与 ADX(1h) 至少其一 ≥ 25，确认存在可交易趋势；
- 做多：价格整体位于 1h/4h EMA20 与 EMA50 之上，均线多头排列；
- 做空：价格整体位于 1h/4h EMA20 与 EMA50 之下，均线空头排列；
- BTC 的 1h/4h 方向与本标的趋势大致一致，避免在大盘转向时逆势做回抽。

若趋势本身不够干净或多周期信号互相矛盾 → 本策略本轮应优先 `wait`，交由其他策略评估。

## 2. 回抽位置与形态质量

- 当前价已经从前期扩张高点/低点**回落至 EMA20–EMA50 区域内**，而不是仍然远离均线；
- 回抽区间与常见 Fibonacci 回撤位（0.382/0.5/0.618）存在共振；
- K 线形态在 EMA 区附近出现止跌/止涨信号（Pinbar、吞没、小双底/双顶等），止损可以合理放在 EMA50 或前一波段极值之外；
- 回调时成交量温和或缩量，属于“健康回撤”，而不是巨量砸盘/恐慌抛售。

若价格尚未回到 EMA 区（仍在扩张末端），或已经明显跌穿/涨穿 EMA50 并破坏结构 → 倾向 `wait`。

## 3. 否决条件（任一满足 → `wait`）

- 价格相对 1h EMA20 仍然扩张 >3–4%，却试图按 Pullback 策略入场，本质是追价而非回抽；
- 最近单根或少数几根 K 线出现极端大幅波动（长上/下影 + 巨量），且价格大幅穿透 EMA 区域，结构被破坏；
- BTC 在关键周期上出现与本标的相反的大级别反转信号（例如 BTC 4h 多转空，而本标的仍想做多回抽）。

出现上述任一情形，本策略不再适用，应优先选择 `wait` 或交给其他策略处理。

## 4. 账户与组合过滤

- 当前保证金使用率 < 70%，否则本轮 Pullback 交易应优先 `wait`，避免在趋势回抽策略上额外加杠杆；
- 若近期连续 2–3 笔 Pullback 交易亏损，说明当前趋势结构可能混乱或假突破频繁：
  - 只有当新的回抽信号非常干净（趋势重新确立、回抽到关键 EMA/Fib 共振区）时才允许再出手；
  - 否则显著收紧触发条件，更偏向 `wait`。
