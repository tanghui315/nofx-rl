# 策略名称：Range Grid (震荡网格)
**核心逻辑**：在震荡区间内（ADX < 20），利用布林带或区间边界进行高抛低吸。

**适用场景**：
- ADX (4h) < 20，市场无明显趋势
- 布林带缩口并走平
- 价格在明显的支撑阻力区间内波动

**交易规则**：
1. **入场**：
   - **做多**：价格触及布林带下轨或区间下沿，且 RSI < 30 出现底背离。
   - **做空**：价格触及布林带上轨或区间上沿，且 RSI > 70 出现顶背离。
   - 必须使用 `LIMIT` (限价单) 挂单入场，严禁市价追单。
2. **止损**：
   - 窄止损：放置在区间边界外侧一点点。如果区间破位，立即离场（转为趋势策略）。
3. **止盈**：
   - 目标明确：布林带中轨（平一半），对侧轨（全平）。
4. **指标过滤**：
   - 重点关注 KDJ 或 RSI 的超买超卖回归信号。

**订单类型**：
- 强制使用 `LIMIT` (限价) 订单。
- 推荐开启 `PostOnly` (只做Maker) 以节省手续费。

# 开仓前确认清单（Range Grid 专用）

**总体原则**：只有在“震荡明显、区间清晰、无趋势化迹象”时才允许开新网格单；一旦环境开始趋势化，应优先 `wait` 或交给趋势策略处理，而不是勉强继续做 Range。

## 1. 环境确认（必须通过）

- ADX(4h) < 20 且 ADX(1h) < 20，确认当前是低趋势强度的震荡市；
- 布林带带宽处于收缩或温和水平，走平而不是持续张口；
- 至少在最近数小时内，价格已经多次在同一上下边界附近反复测试，区间上沿/下沿大致稳定。

若 ADX 明显抬升或布林带大幅张口，说明市场逐渐趋势化 → 本策略本轮应优先 `wait`，而不是再开新网格。

## 2. 入场位置与信号质量

- 做多：当前价接近区间下沿或布林带下轨（距离边界一般 ≤1–1.5%），且 RSI/KDJ 等出现超卖回归或底背离信号；
- 做空：当前价接近区间上沿或布林带上轨（距离边界一般 ≤1–1.5%），且 RSI/KDJ 等出现超买回归或顶背离信号；
- 区间高度足够，扣除手续费后，往返网格仍有合理空间（结合全局 RR 与手续费约束）。

若当前价位于区间中部附近，或离区间边界太远（>1.5–2%），不适合开新网格单 → 倾向 `wait`。

## 3. 趋势化与突破否决（任一满足 → `wait`）

- 价格以放量方式有效突破区间上沿/下沿（收盘站稳区间外），或连续多根单方向大阳/大阴 K；
- ADX 从低位快速上升至 >20–25，布林带明显扩张，价格沿单侧轨道“贴边走”；
- 出现重大新闻驱动或极端波动，短时间内波幅远超此前区间高度。

出现上述任一情形时，Range Grid 策略不再适用，应选择 `wait`，并交由趋势/突破类策略评估是否介入。

## 4. 账户与组合过滤

- 当前保证金使用率 < 70%，否则优先 `wait`，避免在震荡策略上占用过多风险敞口；
- 若最近 2–3 笔 Range Grid 交易连续亏损，说明当前区间不稳定或环境不利于区间交易：
  - 仅当新一轮信号非常干净（区间重新建立、假突破洗掉一批极端仓位）时才谨慎恢复出手；
  - 否则应显著降低出手频率，更多使用 `wait`。
