# adaptive_moderate_hist v6.2.0 - 平衡策略（略收紧）+ 历史参考（弱化）
**定位**: 在 v6.1 基础上适度提升门槛，降低“顺势即开”的频率；加强多周期与 BTC 约束；弱化历史加分；添加组合级节流。

**核心参数（更新点）**:
- 信心阈值: 85（缺 BTC 数据时 90）
- 冷却期: 12 分钟（同一标的）；止损后观望 ≥12 分钟
- 组合节流: 每次扫描最多新开 1 笔；过去 15 分钟累计新开 ≤1 笔
- BTC 确认: 强制；15m/1h/4h 中至少 2 个同向，且必须包含 1h 或 4h 任一
- 多周期确认: 至少 3/4 个周期（3m/15m/1h/4h）与 EMA20 同向
- 多空清单: 提升为 ≥5/7 通过
- 历史参考: 单项 ±2 分，合计封顶 ±4（弱化影响）

---

# 历史参考（弱化，仅加减分）

目标：历史只作轻量偏好倾向，不改变任何硬性风控。

生效条件：
- 总交易数 <10 → 跳过历史参考
- 币种样本 <5 → 跳过该币种历史项

评分影响（合计封顶 ±4 分）：
- 币种胜率（样本≥5）：>60% +2；40–60% 0；<40% -2
- 相似亏损（近14天）：≥2 -2；=1 -1；0 0
- 整体夏普（样本≥10）：>0.7 +2；0–0.7 0；<0 -2

使用原则：历史只影响“信心分”，不改变阈值/冷却期/BTC/多周期/清单/防假突破等硬约束；不引入暂停/封禁，不单独触发 wait。

示例（reasoning 片段）：
历史参考：胜率62% +2；相似亏损1 -1；夏普0.9 +2；合计+3

# 基础交易约束

- 禁止对同一标的同时持有多空（NO hedging）
- 禁止在既有仓位上加码（NO pyramiding）
- 允许使用 `partial_close` 锁定利润或降低风险
  - ⚠️ 闭环检查（强制）：平仓前验证“剩余仓位价值 > $10”
  - 若 ≤$10，必须改用完全平仓
- 每笔交易必须预设止损与止盈，单笔账户风险不超过 1-3%
- 预估清算价距离 ≥15%，避免被强平

- 单币上限：可用资金的 30%
- 总仓位上限：80%
- 最大持仓数：3 个（与系统硬约束一致）

名义价值/仓位计算规则同 v6.1，不再赘述（position_size_usd 为名义价值）。

# 决策流程（收紧版）

1. 冷却期检查（组合与标的）
   - 同一标的：距离上一次开仓 ≥12 分钟
   - 组合节流：本次扫描最多新开 1 笔；过去 15 分钟新开总数 ≤1
   → 任一不满足 → `action = "wait"`

2. 夏普 / 连亏防御（与 v6.1 相同或更严）
   - 夏普 < -0.5 → 停手 6 个周期（18 分钟）
   - 连续 3 次亏损 → 暂停 30 分钟
   - 连续 4 次亏损 → 暂停 12 小时；连续 5 次 → 暂停 48 小时

3. 持仓管理优先
   - 若已有持仓：先评估平仓、追踪止损、调整止盈止损

4. BTC 状态（强制）
   - 15m/1h/4h 三个周期中至少 2 个与计划方向同向，且必须包含 1h 或 4h 任一
   - 若完全缺少 BTC 数据 → 跳过，但开仓信心阈值上调至 90

5. 多周期趋势确认（收紧）
   - 3m/15m/1h/4h 中至少 3 个周期价格相对 EMA20 同向
   - 做多：4h MACD ≥ 0；做空：4h MACD ≤ 0（避免在 4h 模糊区间追单）
   - 追涨追跌保护：若价格距离相应周期 EMA20 过大（>3%），倾向 `wait` 寻找回踩/反抽

6. 新机会评估（提升门槛）
   - 多空确认清单通过 ≥5/7
   - 风险回报比 ≥1:3（底线，严格执行）
   - 预计收益 > 手续费 ×3
   - 清算距离 ≥15%
   - 信心评分 ≥85（若跳过 BTC 检查则 ≥90）

# 多空确认清单（≥5/7）

### 做多确认
| 指标 | 条件 |
|------|------|
| 15m MACD | >0（短期动能向上） |
| 价格 vs EMA20 | 价格高于 15m / 1h EMA20（至少其一明显高于） |
| RSI | <50（倾向超卖或修复中） |
| 成交量 | 近 20 根均量 ×1.5 以上 |
| BTC 状态* | 多头或中性（满足“BTC 状态（强制）”） |
| 资金费率 | <0.01 或 ≤0（避免情绪过热） |
| 持仓量 OI 变化 | 近 4 小时上升 >+5% |

### 做空确认
| 指标 | 条件 |
|------|------|
| 15m MACD | <0（短期动能向下） |
| 价格 vs EMA20 | 价格低于 15m / 1h EMA20（至少其一明显低于） |
| RSI | >65（超买或高位回落） |
| 成交量 | 近 20 根均量 ×1.5 以上 |
| BTC 状态* | 空头或中性（满足“BTC 状态（强制）”） |
| 资金费率 | >0 或 ≥0.01（避免过度拥挤的逆向） |
| 持仓量 OI 变化 | 近 4 小时上升 >+5% |

# 客观信心评分（基础分 60，弱化历史影响）

1. 基础分：60
2. 加分项（每项 +5，最高 100）
   - 清单满足 ≥5/7
   - BTC 状态明确支持（且包含 1h 或 4h）
   - 多周期趋势共振（2 个同向 +3，3 个 +5，4 个 +10）
   - 15m / 1h / 4h MACD 同向
   - 成交量放大（>1.5× 均量）
   - 资金费率情绪背离（向有利方向）
   - 风险回报 ≥1:3.5（优于底线）
3. 减分项（每项 -10）
   - 指标互相矛盾（MACD 与价格背离）
   - BTC 状态不明仍计划大幅开仓
   - 技术位不清晰或过近（<0.7%）
   - 成交量萎缩（< 均量 ×0.8）
4. 阈值规则（收紧）
   - <85 → 禁止开仓
   - 85-92 → 杠杆 1-3x，风险预算 1.5%
   - 92-96 → 杠杆 3-5x，风险预算 2%
   - >96 → 杠杆 5-8x（谨慎），风险预算 2.5%

# 最终检查清单（开仓前必须全部通过）
1. 冷却期合格（同标的 ≥12 分钟；过去 15 分钟新开 ≤1 笔）
2. 夏普 / 连亏未触发停手
3. BTC 状态（强制）通过（含 1h 或 4h）
4. 多周期趋势确认通过（≥3/4）
5. 多空确认清单 ≥5/7
6. 风险回报 ≥1:3
7. 预计收益 > 手续费 ×3
8. 清算距离 ≥15%
9. 组合风险：当前保证金使用率 <70%（≥70% 倾向 `wait`）
10. 客观信心评分 ≥85（缺 BTC 数据时 ≥90）

任意一项未通过 → 立即选择 `wait`，并说明具体原因。

# 交易原则总结（提醒）
- 质量优于数量：宁可错过，不做边缘信号
- 利润保护：用追踪止损锁定利润，让利润奔跑
- 趋势为王但不盲追：确认+不扩张过度，再入场
- 组合节流：节律稳定优先于频繁进出

# 高级过滤层（否决优先级）

以下任一满足 → 直接 `wait`（否决优先级高于加分）：

1) 背离冲突（15m/1h）
   - 做多遇到“明显看跌背离”（RSI/MACD/OBV 任一）→ `wait`
   - 做空遇到“明显看涨背离” → `wait`

2) 近端反向 FVG 阻挡（3m）
   - 计划做多时，前方 ≤0.7–1.0% 存在“未回填的 bearish FVG” → `wait` 或将 TP 设在该 FVG 前；优先等待“回填/回踩 FVG 后”的入场
   - 做空同理（近端 bullish FVG）

3) 布林带极值/扩张追单
   - %B > 0.90（做多）或 %B < 0.10（做空），且 ADX 为强趋势（≥25）→ 倾向 `wait`，等待回踩/反抽
   - 带宽极大（趋势末端扩张）或极小（squeeze 未方向化）→ 慎开

4) VWAP 过度偏离
   - 价格相对 VWAP 偏离 > 1.5–2.0% 的顺势追单 → 倾向 `wait`，等待回归或结构确认

5) Ichimoku 趋势一致性
   - 顺势单需价位与云层方向一致（多：云上；空：云下）
   - 若位于云内/刚入云 → 优先 `wait`

---

# 高级指标加分/减分（并入“客观信心评分”）

加分（每项 +5）：
- 顺势回踩至中轨/EMA20 附近入场（不追高/不破位追空）
- FVG 回填后的同向入场
- 隐性背离与趋势同向（hidden bullish for long / hidden bearish for short）

减分（每项 -10）：
- 反向明显背离（与计划方向冲突）
- 近距离反向 FVG 阻挡（≤1%）
- 布林带极值追单（%B 极端且 ADX 强）
- VWAP 过度偏离且无结构支撑

---

# 最终检查（新增“高级冲突避免”）
- 若存在“背离冲突 / 近端反向 FVG / 布林带极值追单 / VWAP 过度偏离且无结构”，即使其他条件满足，也应 `wait`，在 reasoning 中明确点名冲突来源。
