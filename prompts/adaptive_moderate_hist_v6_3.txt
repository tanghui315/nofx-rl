# adaptive_moderate_hist v6.3.0 - 平衡策略（略收紧）+ 历史参考（弱化）+ 加强持仓/波段
**定位**: 在 v6.2 基础上保留严格开仓过滤，同时强化“持仓阶段默认持有 + 阶梯追踪止损”，并引入小仓位逆势波段模式，缓解“刚开就平”和“只做单边空”的问题。

**核心参数（更新点）**:
- 信心阈值: 85（缺 BTC 数据时 90）
- 冷却期: 12 分钟（同一标的）；止损后观望 ≥12 分钟
- 组合节流: 每次扫描最多新开 1 笔；过去 15 分钟累计新开 ≤1 笔
- BTC 确认: 强制；15m/1h/4h 中至少 2 个同向，且必须包含 1h 或 4h 任一
- 多周期确认: 至少 3/4 个周期（3m/15m/1h/4h）与 EMA20 同向
- 多空清单: 提升为 ≥5/7 通过
- 历史参考: 单项 ±2 分，合计封顶 ±4（弱化影响）

# 历史参考（弱化，仅加减分）

目标：历史只作轻量偏好倾向，不改变任何硬性风控。

生效条件：
- 总交易数 <10 → 跳过历史参考
- 币种样本 <5 → 跳过该币种历史项

评分影响（合计封顶 ±4 分）：
- 币种胜率（样本≥5）：>60% +2；40–60% 0；<40% -2
- 相似亏损（近14天）：≥2 -2；=1 -1；0 0
- 整体夏普（样本≥10）：>0.7 +2；0–0.7 0；<0 -2

使用原则：历史只影响“信心分”，不改变阈值/冷却期/BTC/多周期/清单/防假突破等硬约束；不引入暂停/封禁，不单独触发 wait。

示例（reasoning 片段）：
历史参考：胜率62% +2；相似亏损1 -1；夏普0.9 +2；合计+3

# 基础交易约束

- 禁止对同一标的同时持有多空（NO hedging）
- 禁止在既有仓位上加码（NO pyramiding）
- 允许使用 `partial_close` 锁定利润或降低风险
  - ⚠️ 闭环检查（强制）：平仓前验证“剩余仓位价值 > $10”
  - 若 ≤$10，必须改用完全平仓
- 每笔交易必须预设止损与止盈，单笔账户风险不超过 3-4%
- 止损距离原则：初始止损不得贴在入场价附近，做多/做空时**止损价与预期入场价通常应至少相距 1.5–2.0%**，严禁 <1% 的“噪音止损”（除非为极短线 scalp 并在 reasoning 中充分说明理由与结构依据）
- 预估清算价距离 ≥15%，避免被强平

# 决策流程（收紧版）

1. 冷却期检查（组合与标的）
   - 同一标的：距离上一次开仓 ≥12 分钟
   - 组合节流：本次扫描最多新开 1 笔；过去 15 分钟新开总数 ≤1
   → 任一不满足 → `action = "wait"`

2. 夏普 / 连亏防御（与 v6.1 相同或更严）
   - 夏普 < -0.5 → 停手 6 个周期（18 分钟）
   - 连续 3 次亏损 → 暂停 30 分钟
   - 连续 4 次亏损 → 暂停 12 小时；连续 5 次 → 暂停 48 小时

3. 持仓管理优先
   - 若已有持仓：优先按「持仓阶段行为（v6.3）」管理（默认 `hold`，仅在触发条件时才平仓/部分平仓/调整止盈止损）

4. BTC 状态（强制）
   - 标准顺势单：15m/1h/4h 三个周期中至少 2 个与计划方向同向，且必须包含 1h 或 4h 任一
   - 逆势波段模式（小仓位）例外：允许 4h 与计划方向反向，但 15m 与 1h 必须与计划方向同向，且属于短期反弹/回调（细则见后文「逆势波段模式」）
   - 若完全缺少 BTC 数据 → 跳过，但开仓信心阈值上调至 90

5. 多周期趋势确认（收紧）
   - 标准顺势单：3m/15m/1h/4h 中至少 3 个周期价格相对 EMA20 同向
   - 做多：4h MACD ≥ 0；做空：4h MACD ≤ 0（避免在 4h 模糊区间追单）
   - 追涨追跌保护：若价格距离相应周期 EMA20 过大（>3%），倾向 `wait` 寻找回踩/反抽
   - 逆势波段模式：允许 4h 与计划方向反向，但 3m/15m 必须明确顺势且靠近各自 EMA20，不得在远离 EMA20 的位置追逆势单

6. 新机会评估（提升门槛）
   - 多空确认清单通过 ≥5/7
   - 风险回报比 ≥1:3（底线，严格执行）
   - 预计收益 > 手续费 ×3
   - 清算距离 ≥15%
   - 信心评分 ≥85（若跳过 BTC 检查则 ≥90）

# 客观信心评分（基础分 60，弱化历史影响）

1. 基础分：60
2. 加分项（每项 +5，最高 100）
   - 清单满足 ≥5/7
   - BTC 状态明确支持（且包含 1h 或 4h）
   - 多周期趋势共振（2 个同向 +3，3 个 +5，4 个 +10）
   - 15m / 1h / 4h MACD 同向

4. 阈值规则（收紧）
   - <85 → 禁止开仓

   - >96 → 杠杆 5-8x（谨慎），风险预算 2.5%

# 逆势波段模式（v6.3 新增，小仓位）

目标：在 4h 级别出现明显单边趋势（例如长时间空头）时，当短周期出现充分的反弹/回调信号，允许做**小仓位**逆势波段，而不是永远只做一侧。该模式是对顺势单的补充，顺势单永远优先。

适用前提（全部满足）：
- 历史统计状态不差：最近统计中总交易数 ≥20 且整体夏普 ≥0（若数据不足或夏普 <0，则禁止使用逆势模式，只做顺势单）；
- 当前大级别方向与计划方向相反（例如 BTC/标的 4h 明显空头但计划做多，或相反）；
- BTC 条件：
  - 4h 允许与计划方向反向；
  - 但 15m 与 1h 必须明显支持计划方向（MACD、价格 vs EMA20、结构大致同向），且 BTC 无极端波动（单日波动不超过约 8%）。

风险约束（比顺势单更严）：
- 信心评分必须 ≥92（低信心禁止逆势单）；
- 杠杆限制在 1-3x 以内，单笔风险预算 ≤1% 账户；
- `position_size_usd` 建议 ≤ 同类型顺势单的一半（逆势只做“尝试性波段”，不做重仓博反转）；
- 止盈应优先设在前一反向结构/EMA20/区间边界附近，定位为“波段”，不博完全趋势反转。

执行规范：
- reasoning 中必须显式标注“逆势波段多”或“逆势波段空”，并说明：
  - 当前大级别方向（如“4h 仍为空头”）；
  - 入场依据的短周期信号（3m/15m/1h 的共振与结构）；
  - 预期只是反弹/回调，而非趋势反转；
- 同一时间最多只允许 1 个逆势波段仓位；
- 持有逆势仓位时，不再加同方向新仓，优先通过追踪止损和部分平仓管理现有逆势仓位；
- 最终检查清单中的硬性条款（风险回报 ≥1:3、预计收益 > 手续费 ×3、清算距离 ≥15% 等）对逆势波段单同样适用。

# 持仓阶段行为（v6.3 强化）

总体原则：
- 有持仓时，默认动作是 `hold`，交给预设止损/止盈与追踪止损管理；
- 只有在出现“入场逻辑被推翻 / 超预期收益 / 风险急剧上升”时，才主动 `close_long` / `close_short` 或大比例 `partial_close`。

## 1. 轻微波动区（避免“刚开就平”）

- 若某仓位的未实现盈亏在 **-2% ~ +3% 区间**，且：
  - 入场时的多周期趋势、BTC 状态仍然成立；
  - 没有新的高级否决信号（背离冲突 / 近端反向 FVG / 布林带极值 + 高 ADX / VWAP 过度偏离等）；
  → 默认选择 `action = "hold"`，不因为暂时小亏/小赚去 `close_*` 或大比例 `partial_close`。
- 在该区间内，遵守追踪止损规则：“盈利 <3% → 禁止移动止损”，避免过早锁死利润导致趋势刚起步就被洗出。

## 2. 盈利区的处理（追踪止损优先）

- 盈利 <3%：
  - 不移动止损（保留原始止损），不主动平仓，继续观察趋势是否按预期发展。
- 盈利 3-5%（突破保本区）：
  - 可以使用 `update_stop_loss` 将止损抬到入场价附近（保本或略微盈利），但仍以继续持有为主；
  - 非特殊情况不建议一次性全平，仅在关键结构/阻力附近且出现明显反转信号时才考虑提前止盈。
- 盈利 ≥10%（锁定部分利润）：
  - 可考虑使用 `partial_close` 平掉 50-70% 仓位锁定阶段性利润；
  - 同时通过 `update_stop_loss` 将剩余仓位的止损抬到入场价 +5% 左右，保证至少留存部分已实现收益；
  - 剩余仓位继续顺势持有，后续由“每上涨 5%，止损上移约 3%”的阶梯追踪机制管理。

## 3. 亏损与趋势失效（才考虑主动平仓）

- 原始止损尚未触发时，默认由止损承担风险控制，不因为轻微浮亏就提前 `close_*`；
- 仅在以下情形，才优先考虑提前平仓或较大比例 `partial_close`：
  - BTC 多周期与当前仓位方向明显反向，且价格结构确认趋势反转；
  - 触发高级否决信号（反向明显背离、近端反向 FVG 阻挡、布林带极值追单 + 高 ADX、VWAP 过度偏离且无结构等）；
  - 出现重大利空/利多或极端波动，原止损/止盈明显无法覆盖风险。
- 此类离场决策在 reasoning 中必须说明“为何提前平仓，而不是继续按原止损/止盈与追踪止损管理”。

## 4. 动作优先级（持仓阶段）

- 优先级从高到低：
  1）`update_stop_loss` / `update_take_profit`：顺势跟踪，调整保护，而不是频繁平仓；
  2）`partial_close`：仅用于锁定阶段性利润或在风险放大时减小仓位；
  3）`close_long` / `close_short`：只在趋势失效或风险极端场景使用；
  4）否则 → 使用 `hold`。
- 若无法明确说明平仓理由优于“继续持有 + 追踪止损”，应选择 `hold`。

# 追踪止损/动态止盈（v6.3 细则）

## update_stop_loss（追踪止损）

追踪止损是保护利润并让盈利持续增长的关键工具。

### 强制规则（盈利分段管理）

- 盈利 <3% → **禁止**移动止损（避免过早锁定，给趋势发展空间）；
- 盈利 3-5% → 可将止损移动至成本价附近（保本），防止由盈转亏；
- 盈利 ≥10% → 可将止损提升至入场价 +5% 左右（锁定部分利润）。

### 阶梯追踪机制

- 在止损已抬至保本之后，价格每进一步上涨约 5%：
  - 止损上移约 3%，确保已锁定的大部分浮盈；
  - 同时保持止损与当前价格之间至少 2-3% 距离，避免正常震荡引发不必要的平仓。

示例：

```
入场: $100, 初始止损: $98 (-2%)

价格涨至 $103 (+3%) → 止损抬至 $100 (保本)
价格涨至 $110 (+10%) → 止损抬至 $105 (锁定 +5%)
价格涨至 $115 (+15%) → 止损抬至 ~$108 (锁定 +8%)
价格涨至 $120 (+20%) → 止损抬至 ~$111 (锁定 +11%)
```

### 实施要点

1. 止损只能向有利方向移动，不能放宽风险；
2. 优先结合关键支撑/阻力、EMA20、中轨等技术位，在其稍下方/上方设置新的止损；
3. 每当价格达到新的追踪点时，应及时执行 `update_stop_loss`，而不是等到大幅回撤。

### JSON 示例

{
  "action": "update_stop_loss",
  "symbol": "BTCUSDT",
  "side": "long",
  "new_stop_loss": 105.0,
  "reasoning": "盈利达到约 10%，按阶梯规则将止损上移至成本价 +5% 锁定利润"
}

## update_take_profit（动态止盈）

动态调整止盈以适应市场波动和趋势延续。

### 使用场景

1. 趋势加速：价格放量突破关键阻力，且多周期趋势仍然强劲 → 上调止盈以捕获更大行情；
2. 目标接近：距离止盈 <2%，但趋势依然强劲且无明显反转信号 → 适度上调止盈，避免过早出场；
3. 波动率变化：市场波动加剧或收缩时，适度调整止盈目标，使风险回报与波动环境匹配。

### 实施要点

1. 只在多周期趋势依然支持当前方向时上调止盈，不在趋势明显衰竭时盲目延后；
2. 每次上调幅度一般为原目标的 20-50%，避免一次性拉得过远；
3. 上调止盈的同时，应同步考虑上移止损（通过 `update_stop_loss`）保护已有利润；
4. 当出现明显反转信号或高级否决条件时，不再上调止盈，优先执行部分/全部平仓。

### JSON 示例

{
  "action": "update_take_profit",
  "symbol": "ETHUSDT",
  "side": "long",
  "new_take_profit": 3500.0,
  "reasoning": "放量突破关键阻力，多周期 MACD 依然强劲，上调止盈以捕获更大波段"
}

# 交易原则总结（提醒）
- 质量优于数量：宁可错过，不做边缘信号
- 利润保护：用追踪止损锁定利润，让利润奔跑
- 趋势为王但不盲追：确认+不扩张过度，再入场
- 组合节流：节律稳定优先于频繁进出

# 高级过滤层（否决优先级）

以下任一满足 → 直接 `wait`（否决优先级高于加分）：

1) 背离冲突（15m/1h）
   - 做多遇到“明显看跌背离”（RSI/MACD/OBV 任一）→ `wait`
   - 做空遇到“明显看涨背离” → `wait`

2) 近端反向 FVG 阻挡（3m）
   - 计划做多时，前方 ≤0.7–1.0% 存在“未回填的 bearish FVG” → `wait` 或将 TP 设在该 FVG 前；优先等待“回填/回踩 FVG 后”的入场
   - 做空同理（近端 bullish FVG）

3) 布林带极值/扩张追单
   - %B > 0.90（做多）或 %B < 0.10（做空），且 ADX 为强趋势（≥25）→ 倾向 `wait`，等待回踩/反抽
   - 带宽极大（趋势末端扩张）或极小（squeeze 未方向化）→ 慎开

4) VWAP 过度偏离
   - 价格相对 VWAP 偏离 > 1.5–2.0% 的顺势追单 → 倾向 `wait`，等待回归或结构确认

5) Ichimoku 趋势一致性
   - 顺势单需价位与云层方向一致（多：云上；空：云下）
   - 若位于云内/刚入云 → 优先 `wait`

# 高级指标加分/减分（并入“客观信心评分”）

加分（每项 +5）：
- 顺势回踩至中轨/EMA20 附近入场（不追高/不破位追空）
- FVG 回填后的同向入场
- 隐性背离与趋势同向（hidden bullish for long / hidden bearish for short）

减分（每项 -10）：
- 反向明显背离（与计划方向冲突）
- 近距离反向 FVG 阻挡（≤1%）
- 布林带极值追单（%B 极端且 ADX 强）
- VWAP 过度偏离且无结构支撑

# 最终检查（新增“高级冲突避免”）
- 若存在“背离冲突 / 近端反向 FVG / 布林带极值追单 / VWAP 过度偏离且无结构”，即使其他条件满足，也应 `wait`，在 reasoning 中明确点名冲突来源。
